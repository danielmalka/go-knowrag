# Exact versions of everything the embedder service runs on (owner's decision, 2026-11-15): the
# direct dependencies (sentence-transformers, transformers, torch, torchvision) and every package
# they pull in, as resolved and verified on 2026-11-15 with Python 3.14.4 on Linux x86_64.
#
#   python3 -m venv ~/.venvs/knowrag-embedder
#   ~/.venvs/knowrag-embedder/bin/pip install -r scripts/embedder-service/requirements.txt
#
# Why each direct one is here:
#   - sentence-transformers >= 6.1.0 is what the model repository itself requires (its
#     config_sentence_transformers.json); this is the version tested.
#   - transformers >= 5.18 is where the `embedding_gemma2` architecture lives.
#   - torch from the default index carries CUDA 13 (the nvidia-* packages below); the driver has to
#     support it (`nvidia-smi` shows "CUDA Version").
#   - torchvision is needed even though the service is text only: transformers imports it while
#     resolving the model's processor. The vision and audio towers are not built (config_kwargs in
#     st_adapter.py sets both configs to None), so no VRAM goes to them.
# Upgrading any line is a change to the service: run `make test-embedder` and the GPU tests
# (KNOWRAG_GPU_TESTS=1) first, because the vectors this venv produces are what `point_hash` and the
# stored index are built on.
